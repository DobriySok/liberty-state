# LIBERTY STATE

Полностью браузерный open-world экшен с видом от третьего лица в духе классических GTA —
**написанный с нуля, без единого ассета из оригинальных игр**.

```
Город 512×512 м: центр, жилые кварталы, промзона, парк, пляж, аэродром.
6 миссий · розыск и полиция · трафик · магазины · бронежилеты · сохранения.
Мультиплеер: LAN/интернет БЕЗ сервера (WebRTC P2P, копируешь код в мессенджер).
```

## Запуск

**Вариант 1 (просто):** открыть `index.html` в браузере (Chrome/Firefox/Edge).
Никаких сборок, серверов и зависимостей — Three.js лежит локально в `lib/`.

**Вариант 2 (локальный статик-сервер, по желанию):**
```bash
cd gta-web
python3 -m http.server 8080
# → http://localhost:8080
```

| Клавиша | Действие |
|---|---|
| WASD / стрелки | движение / руль (относительно камеры) |
| Мышь (ЛКМ) | прицел / стрельба (из машины — вперёд) |
| Shift | бег |
| E | сесть/выйти из машины, больница, полиция, магазин, кофейня |
| Пробел | ручной тормоз (в машине) |
| F | гудок (в машине) |
| 1…5 | смена оружия |
| M | карта города |
| N | радио (генеративный чиптюн) |
| Esc | пауза / назад |

## Мультиплеер (без сервера)

Мир детерминированный: хост передаёт сид, все получают один и тот же город.

**Локальный режим (быстрая проверка):** открой игру в двух вкладках одного браузера —
соединение через BroadcastChannel, автоматически.

**LAN / интернет (WebRTC, звёздная топология):**
1. Хост: *Мультиплеер → LAN → «Создать слот»* → копирует **OFFER-код**.
2. Отправляет код игроку (любым мессенджером). Игрок: *«Подключиться»*, вставляет
   OFFER → получает **ANSWER-код** → отправляет его хосту.
3. Хост вставляет ANSWER в «Применить answer» → игроки в одной игре.
4. Повторяй для каждого нового игрока (до 5).

STUN/TURN не нужны в LAN. Через интернет работает, если устройства видят друг друга
(одна подсеть / проброс). Сигналинг — только копия кодов, **никаких серверов**.

## Почему это работает на слабых ПК

- **Стриминг чанков**: мир 512×512 м разбит на чанки 64×64 м, грузятся только вокруг
  игрока (радиус настраивается: высокое/среднее/низкое качество в паузе).
- **Мало draw calls**: все здания чанка — одна геометрия с процедурным UV-атласом
  фасадов; деревья — InstancedMesh; частицы — один Points-меш; тени — blob-инстансы.
- **Low-poly**: город из боксов и цилиндров, ~200–400 тыс. треугольников в кадре.
- Логика — 30 Гц, рендер — каждый кадр; туман скрывает дальние чанки.
- Пиксель-рейшн 1 (опция 2× в высоком качестве).

## Авторское право

Проект оригинальный:

- весь код написан с нуля;
- вся графика (здания, машины, деревья, текстуры, вывески) генерируется кодом;
- вся музыка/звук — процедурный WebAudio (движок, сирена, выстрелы, чиптюн-радио);
- имена, миссии, сюжет — собственные;
- используется только открытая библиотека Three.js (MIT) — это технология, не контент.

Никаких моделей, текстур, звуков, названий и кода из GTA/Rockstar Games.

## Структура

```
index.html          точка входа (скрипты без сборки, работает с file://)
css/style.css       стили меню
lib/three.min.js    Three.js r147 (MIT, UMD — работает без модулей)
js/utils.js         математика, ГПСЧ, коллизии отрезков
js/audio.js         WebAudio: движок, сирена, выстрелы, радио
js/world.js         генерация карты (сид → детерминированный город), граф дорог, BFS
js/city3d.js        Three.js: чанки, атласы, вода (шейдер), частицы, камера
js/meshes.js        процедурные 3D-модели машин/пешеходов/игрока
js/entities.js      игрок, физика машин, пешеходы, пули, взрывы, розыск
js/ai.js            трафик, полиция (погоня, таран, арест), соперники
js/missions.js      6 миссий
js/multiplayer.js   WebRTC (copy-paste сигналинг) + BroadcastChannel
js/save.js          сохранения (localStorage)
js/hud.js           2D-HUD: миникарта, розыск, оружие, тосты
js/ui.js            DOM-меню: титул, пауза, магазин, мультиплеер
js/main.js          игровой цикл (30 Гц), ввод, состояния
```
