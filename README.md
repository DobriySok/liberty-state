# LIBERTY STATE II

Браузерная GTA-подобная песочница, написанная с нуля. Вся логика — клиентский JavaScript (three.js r147, MIT).
Никаких процедурных заливок: только настоящие 3D-модели и фото-текстуры по свободным лицензиям.

## Играть
Открой `index.html` через любой статический сервер (или GitHub Pages этого репо).
Клик по экрану захватывает мышь (pointer lock).

## Управление
| Клавиша | Действие |
|---|---|
| WASD | ходьба / вождение |
| Мышь | камера-орбита (как в SA), колесо — зум |
| ЛКМ / ПКМ | огонь / прицел «в плечо» |
| Shift / Space | бег / прыжок, в машине — ручник |
| E | сесть-выйти из машины (водитель убегает) |
| 1/2/3 | кулаки / пистолет / ПП |
| N / M | радио вкл-выкл / след. трек |

## Что внутри
- Город из реальных моделей: кварталы, асфальт с разметкой, фонари, гидранты, скамейки, водонапорки
- Машины: векторная физика с заносом, ручник, урон, дым, взрывы, collisions
- Пешеходы: анимированные (idle/run/jump), паникуют и разбегаются
- Полиция: звёзды розыска 1–4, погони, обстрел при 3★, арест
- Сутки за 24 минуты: закат, ночь, светящиеся окна
- Миссии: доставка и зачистка, циклично
- HUD: минимапа, деньги, часы, спидометр, звёзды
